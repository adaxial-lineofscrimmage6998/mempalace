## 🛠️ How it works

Mempalace behaves like a database for your thoughts. It organizes information so computer programs can access it.

### Your data storage
The app uses SQLite to keep your notes organized in one place. SQLite acts as a file-based storage system. It requires no extra setup or hidden services. Your notes live in a single file on your hard drive. 

### Integration with AI
This tool connects to AI models to provide context. When you ask an AI a question, it needs information about your past work. Mempalace feeds this data to the AI. This allows the AI to provide answers based on your unique files.

### Support for memory providers
The application supports Turso for cloud syncing. This feature keeps your data consistent across multiple computers. You can enable this in the settings menu if you need to use the app in more than one location.

## 🔍 Frequently Asked Questions

### Does mempalace spy on my data?
All your information stays on your local hard drive. The app does not send your notes to our servers. You remain in control of your files at all times.

### What happens if I lose internet access?
The core functions of mempalace operate offline. You can view, search, and edit your notes without an internet connection. Connection is only required if you use a cloud sync feature like Turso.

### Can I delete my data?
Yes. You can delete notes within the interface. To remove the entire database, delete the storage file located in the application data folder.

### Is this tool safe?
We use Rust to build this software. Rust prevents common memory errors that cause crashes. This approach makes the app stable and secure for daily use.

### Where do I report problems?
If you encounter a bug, create a new issue on the GitHub repository page. Include a description of the problem and the steps you took before the error occurred.
